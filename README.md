# Honggang Yuan

Personal academic homepage of Honggang Yuan (袁红刚), Ph.D. student in Software Engineering at East China Normal University.

The public site is published from this repository with GitHub Pages:

https://hongan-yuan.github.io/hgyuan/

## Layout

Content is separated from presentation so the page copy can be edited without touching the markup.

- `index.html` — biography, experience timeline, and contact
- `publication/` — filterable publication list and BibTeX dialog
- `patents/` — patent list (empty until entries are added)
- `js/data.js` — all English page copy, links, and bibliography
- `js/ui.js` — shared navigation, footer, logos, and the cite dialog
- `js/home.js`, `js/publications.js`, `js/patents.js` — page renderers
- `css/main.css` — layout and visual style
- `assets/portrait.jpg` — portrait
- `assets/Honggang_Yuan_CV.pdf` — curriculum vitae (Chinese)

To preview locally, serve the repository root and open `index.html`. Relative links are used so the same files work on GitHub project pages.
